# Follow-up Message Sequences

3-step follow-up templates for each networking category. **NOT automated** — agent generates drafts, user sends manually.

> Cross-reference: Initial messages in `connection-messages.md`. Pipeline tracking in `agents/outreach-agent.md`.

## Sequence Structure

| Step | Timing | Purpose |
|---|---|---|
| Day 0 | Initial | Connection request (see `connection-messages.md`) |
| Day 3 | Follow-up 1 | Thank-you + value-add |
| Day 7 | Follow-up 2 | Engagement + soft ask |
| Day 14 | Follow-up 3 | Final follow-up with clear CTA |

After Day 14 with no response → move to **passive engagement** (like/comment on their content for 30 days, then reassess).

### Day 3 — Thank + Reconnect

```
שלום [Name], תודה על הקשר! שמח לראות שאתה ב[current role/field].
מה המעבר שלך מחיל רפואה? אשמח לשמוע.

```

```

```

## Universal Rules

1. **Character limits:** Connection messages = 300 chars max; InMail = 1,900 chars
2. **Language:** Hebrew for Israeli contacts (categories 1, 4), English for international (2, 3, 5). Bilingual for mixed contexts.
3. **Personalization required:** Replace ALL [bracketed] placeholders with real data. Reference something specific from their profile.
4. **Medical vocabulary:** Use terms from Medical Lexicon DB where clinically relevant.
5. **Timing:** Send follow-ups during Israeli business hours (Sun-Thu, 08:00-18:00 IST).
6. **No response protocol:** After 3 follow-ups with no response → Status: Cold. Shift to passive engagement (like/comment their content weekly for 30 days).
7. **Pipeline tracking:** Update Outreach Pipeline in Notion after each follow-up sent (Status, Last Touch, Next Action Date).
