## Why Endorsements Matter

- LinkedIn shows the top 3 endorsed skills prominently on the profile
- Endorsed skills improve search ranking for those keywords
- Maya Cohen's insight: "I filter by skills in Recruiter — endorsed skills rank higher in my search results. 5+ endorsements on a key skill makes a real difference."
- Target: 10+ endorsements on each of the top 3 skills within 60 days

## Endorsement Acquisition Strategy

### Phase 1: Reciprocal Endorsements (Week 1-2)

**Principle:** Endorse others first — most professionals reciprocate.

**Steps:**
1. Identify 20 connections who are dental professionals
2. Visit each profile and endorse 3-5 relevant skills
3. Many will reciprocate within 7 days
4. Track endorsements given vs received

**Target per day:** Endorse 3-5 connections (Sun-Thu)

### Phase 2: Direct Requests (Week 3-4)

For close professional contacts who haven't endorsed back:

```
Hi [Name], I noticed you're skilled in [their skill] — I endorsed you!
If you have a moment, I'd appreciate an endorsement for my [top skill].
No worries if not. Cheers!
```

**Keep it casual** — endorsement requests should be low-pressure.

### Phase 3: Ongoing Maintenance (Monthly)

- Endorse new connections within 48 hours of connecting
- After positive interactions, ask for specific skill endorsement
- Review top 3 skills monthly — reorder if a different skill gets more traction
- When publishing a post about microscope work → add note: "If you've seen my microscope work, I'd appreciate an endorsement for Surgical Microscope on my profile!"

## Rules

1. **Only endorse skills you can genuinely vouch for** — don't endorse random skills
2. **Never ask patients directly** — endorsements from patients can appear on profile organically
3. **Don't over-request** — max 1 endorsement request per contact per quarter
4. **Reorder skills strategically** — top 3 visible skills should match recruiter search keywords
5. **Hebrew skill names** — if LinkedIn shows Hebrew skill variants (e.g., אנדודונטיה), accept both language versions as endorsements count toward the same skill
6. **Quality over quantity** — 10 endorsements from dental professionals > 50 from non-relevant contacts
