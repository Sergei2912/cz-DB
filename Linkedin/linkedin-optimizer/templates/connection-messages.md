# Connection Message Templates

## 1. IDF Alumni (Hebrew recommended)

### Template
```
Hi [Name], we both served in IDF Medical Corps — I was a Captain at [unit/base]
from 2015 to 2023. I'm returning to Israeli dental practice after gaining
European experience and would love to reconnect. Would be great to catch up!
```

### Variables
- `[Name]` — first name of the connection
- `[unit/base]` — shared unit or base reference

### Hebrew variant
```
היי [Name], שנינו שירתנו בחיל הרפואה — שירתתי כקצין מ-2015 עד 2023.
חזרתי לישראל אחרי ניסיון קליני באירופה ואשמח לחדש קשר. מה שלומך?
```

## Usage Notes
- **Max 300 characters** for LinkedIn connection requests (without Premium)
- **InMail** (Premium): up to 1,900 characters
- Always personalize — never send verbatim templates
- Reference something specific from their profile when possible
- Hebrew messages for Israeli contacts, English for international
